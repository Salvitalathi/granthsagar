ग्रंथसागर — PDF इथे टाका
==========================

या folder मध्ये तुमच्या ग्रंथांच्या PDF किंवा PDF असलेली ZIP टाका.

* ग्रंथसागर चालू असेल तर 20 सेकंदांत तो स्वतः काम सुरू करतो.
* ZIP आपोआप extract होते.
* Scan केलेल्या / जुन्या font मधील PDF चा OCR होतो (हिंदी/मराठी + संस्कृत, ॐ सह).
* तयार मजकूर granth\pdf\<ग्रंथाचे नाव>\ मध्ये जातो आणि आपोआप वाचला जातो.
* पूर्ण झालेल्या मूळ फाइल्स done\ मध्ये हलवल्या जातात.
* उघडता न आलेल्या PDF failed\ मध्ये, कारण लिहिलेल्या .txt सह.

विषयानुसार folders (ग्रंथ त्या विषयाच्या agent ला मिळतो):
  ज्योतिष\   आयुर्वेद\   पुराण\   मंत्र\
  उदा. सूर्यसिद्धांत.pdf -> pdf_inbox\ज्योतिष\ मध्ये टाका -> मजकूर granth\pdf\ज्योतिष\ मध्ये -> ज्योतिष agent.
  folder बाहेर टाकलेले ग्रंथ 'सर्व ग्रंथ' मध्ये मिळतात.

प्रगती ग्रंथसागरच्या पानावर वर नारिंगी पट्टीत दिसते.
दुसरा मार्ग: chat मधील "📄 PDF जोडा" बटण.
