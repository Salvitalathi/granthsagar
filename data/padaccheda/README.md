# पदच्छेद-माहिती

Digital Corpus of Sanskrit (DCS) — Oliver Hellwig, https://github.com/OliverHellwig/sanskrit — **CC BY 4.0**.
प्रत्येक ओळ = एक श्लोकार्ध/वाक्य: मूळ मजकूर (`t`, IAST), आणि प्रत्येक पद `[रूप, मूळ शब्द, शब्दजाती, व्याकरण]`.
`scripts/build_padaccheda.py` ने बनवले. ग्रंथसागर पहिल्या वापराला यातून `tools/padaccheda.db` बनवतो (~30 सेकंद, ~200 MB).
