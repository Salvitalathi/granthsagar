# 🪔 ग्रंथसागर

वेद, उपनिषदे, पुराणे, आयुर्वेद आणि मंत्र-ग्रंथ वाचून **मराठीत अर्थ समजावणारा**, तुमच्या संगणकावर **offline** चालणारा AI.

- ग्रंथांमधून नेमका श्लोक शोधतो आणि `[अथर्ववेद (शौनक) 1.1.1]` असा संदर्भ देतो
- श्लोकाचा शब्दार्थ आणि भावार्थ, कथा, आणि ग्रंथानुसार उपाय मराठीत सांगतो
- गंभीर लक्षणे (छातीत दुखणे, बेशुद्धी, गर्भवती इ.) लिहिली तर आधी लाल सूचना दाखवतो
- इंटरनेटशिवाय चालतो ([Ollama](https://ollama.com) + Qwen)

> ⚠️ हा अभ्यासासाठीचा AI आहे. AI चुका करू शकतो. उपचार करण्यापूर्वी प्रमाणित वैद्य किंवा डॉक्टरांचा सल्ला घ्या.

## सुरू करणे (Windows)

1. [Ollama](https://ollama.com) आणि [Python](https://python.org) install करा
2. हा repo download करा (Code → Download ZIP) आणि extract करा
3. `start.bat` वर double-click करा. पहिल्यांदा सुमारे 4.5 GB मॉडेल्स उतरतील
4. Browser मध्ये ग्रंथसागर उघडेल

मॉडेल: **Gemma 3 4B** (`gemma3:4b`). चार मॉडेल्सच्या तुलनेत हेच मराठीत सर्वोत्तम ठरले आणि ते 8 GB RAM वर चालते. 6 GB पेक्षा कमी RAM असेल तर आपोआप `gemma3:1b` निवडले जाते. 16 GB RAM असेल तर `start_12b.bat` वापरा. हे मोठे `gemma3:12b` मॉडेल आहे, ज्याचे अर्थ जास्त अचूक येतात, पण ते हळू चालते. ग्रंथ पहिल्यांदा "वाचायला" (embedding) 1–2 तास लागू शकतात. हे फक्त एकदाच होते, आणि नंतर ग्रंथसागर लगेच सुरू होतो.

## ग्रंथ जोडणे

| कसे | काय करायचे |
|---|---|
| आधीच समाविष्ट | अथर्ववेद (Whitney भाषांतरासह), सुश्रुत संहिता, चरक संहिता — `granth/` मध्ये |
| DCS वरून आणखी (पुराणे, अष्टांगहृदय, भावप्रकाश…) | `python scripts/dcs_granth.py --list` → उदा. `python scripts/dcs_granth.py bhagavata garuda` (git लागते) |
| GRETIL वरून (संस्कृत) | `python scripts/download_granth.py` → `python granth_tayar.py` |
| इतर कोणताही ग्रंथ | `.txt`, `.pdf` किंवा `.docx` फाइल `granth/` folder मध्ये टाका |
| GRETIL वरील पुराणे | `python scripts/download_granth.py purana` → `python granth_tayar.py` |

### PDF ग्रंथ जोडणे (scan केलेले किंवा कोणत्याही font मधील)

यासाठी काहीही हाताने करावे लागत नाही. खालीलपैकी कोणताही एक मार्ग वापरा:
- chat मधील **📄 PDF जोडा** बटण दाबा, PDF किंवा **PDF असलेली zip** निवडा, आणि "अपलोड" दाबा. ग्रंथाचे नाव देणे ऐच्छिक आहे. भाषा "आपोआप ओळखा" वर ठेवा: ग्रंथसागर नमुना पाने वाचून हिंदी की मराठी ते ठरवतो.
- किंवा PDF/zip `pdf_inbox` folder मध्ये (किंवा थेट `granth` मध्ये) टाका. ग्रंथसागर चालू असेल तर तो 20 सेकंदांत ती स्वतः उचलतो.
- zip असेल तर ती आपोआप extract होते (आतील zip, Windows मधील देवनागरी नावे यांसह). आतील PDF चा OCR होतो, आणि .txt/.docx फाइल्स थेट `granth/pdf/<zip चे नाव>/` मध्ये जातात.

ग्रंथसागर स्वतः ठरवतो की PDF चा मजकूर थेट घेता येईल की OCR करावा लागेल. तयार झालेला मजकूर `granth/pdf/<ग्रंथाचे नाव>/` मध्ये save होतो, प्रत्येक पानाला `[ग्रंथ पृ. 12]` असे शीर्षक असते, आणि नंतर तो आपोआप वाचला जातो. मूळ PDF `pdf_inbox/done/` मध्ये हलवली जाते. वरच्या पट्टीत प्रगती दिसते.
`start.bat` लागणारे सगळे (pypdfium2, Tesseract) पहिल्यांदा आपोआप install करते. हिंदी/मराठी OCR भाषा-फाइल गरज पडेल तेव्हा एकदाच उतरवली जाते.
`granth/pdf/` आणि `pdf_inbox/` GitHub वर जात नाहीत, म्हणजे तुमच्या पुस्तकांचा मजकूर तुमच्याकडेच राहतो.

नवीन फाइल टाकल्यावर chat मधील **📂 फाइल्स पुन्हा वाचा** दाबा.

## Folder रचना

```
granthsagar.py         मुख्य app (chat + ग्रंथ शोध + PDF जोडणे)
pdf_ocr.py             PDF → मजकूर (OCR)
granth_tayar.py        IAST → देवनागरी, श्लोक संदर्भ
scripts/download_granth.py   GRETIL वरून ग्रंथ उतरवणे
granth/                तुमचे ग्रंथ (AI इथूनच वाचतो)
tiny_ai/               शिकण्यासाठी: शून्यापासून बनवलेले RNN आणि GPT (फक्त NumPy)
tests/                 offline tests + live test चे प्रश्न
```

## GitHub वर चाचणी

- **Tests (offline):** प्रत्येक push वर आपोआप चालतो
- **Live test (खरा AI):** Actions → "Live test" → Run workflow. GitHub वर Ollama चालवून, ग्रंथ उतरवून `tests/questions.txt` मधील प्रश्न विचारतो. उत्तरे run च्या Summary पानावर दिसतात.
